# Thiết kế bomb

## Các thuộc tính bắt buộc

- ID
- Name
- Radius
- Damage
- IsActivatedOnContact
- FuseTime
- Stages
- AffectOn (Player, Terrain/Object, both)
- CanDestroyTerrain
- Effect (None, Fire, Electrified, Frozen)
- ApplyForceOnExplosions
- Force
- ExplodeMultipleTimes
- NumberOfExplosions
- Audio (Ticking sound, explode sound)
- Explosion Visual Effect
- SpawnAtDifficulty (any, 1-5)
